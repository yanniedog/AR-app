# Security policy

Please do not disclose a suspected vulnerability in a public issue.

Use GitHub's **Report a vulnerability** form in this repository's Security tab. Include the affected app version, device/OS, a minimal reproduction, and any relevant logs with personal or financial information removed.

The maintainers will acknowledge a complete report, assess impact, and coordinate a fix and disclosure. Release-signing keys, tokens, customer data, and exploit details must not be posted publicly.
