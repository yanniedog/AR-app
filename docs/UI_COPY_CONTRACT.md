# UI copy contract

Explanatory application prose is prohibited across every screen, sheet, control, accessibility surface, native dialog, notification and generated report. This is a product requirement. A collapsed panel, renamed prop or native share sheet does not relax it.

The interface uses concise headings, field labels, actions, identity, numeric facts, dates, source references and explicit status. Preserve material conditions and unknowns. An absent fee is unknown; a known zero remains zero. Listed tiers do not establish bank approval. Historical coverage dates do not establish a current offer.

## Admission

| Content | Contract |
| --- | --- |
| Heading, action, field, status, unit | Explicitly reviewed `UI_LABELS` literal |
| Numeric, date, identity or financial fact | A narrow factory bound to that actual model |
| Freeform user input | `UiInputText`, editable controls only |
| PDF HTML | `UiMarkup`, escaped admitted cells and checked tagged literals |
| Legal/licence text | `DocumentText`, fixed document registry only |
| Explicit diagnostic/receipt evidence | Dedicated renderer bound to its actual source/model |

`UiCopy` and `UiChild` close normal display APIs. Native props close titles, placeholders and accessibility text. Description, subtitle, deck, summary, helper, hint and secondary explanatory APIs are removed. Do not add a general `label(string)`, `fact(string)` or cast to bypass admission. New registry entries require semantic review as actions, headings, labels, statuses or facts; never explanatory prose.

Identity factories receive actual identity fields. Do not fabricate an identity model from a paragraph. Source clauses are parsed only when the existing source admission proves the exact product, variant, publication, hash and pointer. Unsupported wording remains `Source review required` and links to its original evidence.

Private edited facts keep their real provenance and encryption. Neither a formatting factory nor a result label may strengthen a monetary, eligibility or source claim. Hashed receipts, calculation arithmetic and persisted inputs retain their original contracts.

## Evidence boundaries

`DocumentText` owns the fixed legal/licence registry. `DebugEvidenceText` owns the bounded local log subscription. `AuditEvidenceText` owns an actual `PerformanceAuditReport`; `ReceiptEvidenceText` owns an admitted `ReplayDocument.original`. The explicit native debug share helper reads the complete local evidence with installed application metadata and accepts only a boolean full-evidence option. These are individual source-bound expressions, not file or route exemptions. All surrounding headings, controls and status remain subject to normal copy rules.

## Enforcement

Run `cd mobile && npm run ci`. Its `check:ui-copy` step builds the real TypeScript program and inspects production app/source text sinks, native calls, spreads, aliases, casts and controlled assignments. The guard verifies brand declaration origins, typed report cells and checked HTML construction. Tests exercise valid boundaries and reject raw/any strings, forged brands/models, fake hooks/factories, unsafe aliases, HTML paragraphs, attributes and CSS content.

No sentence-length heuristic or old-copy baseline is used. Tests are excluded as test fixtures; production routes are not excluded. A guard change must retain the adversarial checks and current zero-violation result. Keep narrow producers and primitives portable; no machine-specific paths, dependencies or native build changes are needed for copy enforcement.
