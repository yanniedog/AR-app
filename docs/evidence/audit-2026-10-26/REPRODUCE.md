These use Node 24.19.0 and the repository Jest/Expo setup, not Hermes or native rendering. Preserve baseline `bf4eaf8ad5cf55a82286c94a0e6170e201cf1569`. Import each baseline and patched exported cooperative function into a temporary Jest test. Remove temporary modules/tests after recording results.

History fixture: use `core` / `row` from `mobile/testUtils/publicRateJourney.ts`; make 3,200 rows with keys `p-${index}`. Date axis is 167 ISO days beginning `2026-01-01`; today's core date is the final date. Use schema 3, `HISTORY_DERIVATION_VERSION`, core hash `unchanged`, and every product series filled with `0.06`. Source identity is `legacy:${date}` for earlier dates and `core:unchanged` for today. Call each implementation five times with `existing`, `allowNetwork:false`, `preparedOnly:true`, and no fallback index/catalogue. Measure each call with Node `performance.now()`. Assert every result's entire `products` object equals the fixture, and count `result === existing`. Report all samples, not only the median. Baseline then patched order and shared-host load are limitations.

Pricing fixture: use `programme`, `product`, `catalogue`, `AS_OF` from the same helper. Make one Savings product and 1,200 Savings programmes. Programme/offer IDs are `p-${index}` / `o-${index}`; update **each component's scopeId to that same offer ID**. An unchanged component scope makes this fixture unresolved and is not a valid pricing benchmark. Call each cooperative offer-expansion implementation five times with `{}` scenario and `asOfForProgramme:()=>AS_OF`. Immediate test yields measure checkpoint boundaries only; they do not measure the real UI scheduler.

The retained regression tests cover semantic equality, high fanout, cancellation, interrupted focus and warm result identity. The two JSON files preserve measured samples and exclusions. They are local proxies, not acceptance evidence for the physical user's device.

## Rendered web scenarios

Use the preserved `rendered-scenarios.cjs` against baseline `git archive bf4eaf8ad5cf55a82286c94a0e6170e201cf1569` and the patched tree, each with its normal installed mobile dependencies. Start task-owned offline Expo development web servers on separate localhost ports, with no unrelated heavy tests running during measurement. Run `node rendered-scenarios.cjs http://localhost:<port> <report.json> <exact-source-label>`. Default three fresh contexts produce3cold/9warm bank opens, plus scroll/back/forward/interruption/scope/forced-timeout/reselection checks. Cold means first bank opening after fixture installation, not boot/network/APK cold start. The harness blocks all non-local browser requests and supplies deterministic source-owned fixtures.

`rendered-acceptance.cjs` adds actual sheet lifecycle proof, comparison destination and CSS150% narrow-viewport text stress. Final argument `one` runs one supplemental context. The legacy supplemental baseline failed after forced timeout recovery; its retained error is evidence, not a completed acceptance run. Do not retry indefinitely or reuse failed runs as success. `rendered-provenance.json` identifies exact report/harness/bundle hashes and version limits.
