# Phase 4: structured facts and copy enforcement

All remaining consumer surfaces use the new shared design and concise actions, fields, identities, results and statuses. Product conditions, eligibility uncertainty, source dates, fees and assumptions remain explicit facts. Calculation arithmetic, encrypted saved inputs and receipt hashes retain their contracts.

The [copy contract](UI_COPY_CONTRACT.md) closes text APIs across screens, sheets, accessibility, native prompts, notifications and exported reports. Explanatory description, subtitle, helper and hint APIs are removed. Canonical CI checks the actual TypeScript program, including aliases, spreads, casts, native calls and generated HTML. Fixed legal documents and explicitly opened source-bound evidence have individual boundaries; no production route is exempt.

The standalone history compiler imports pure numeric, classification and normalization helpers. Frontend copy adapters remain separate. Regenerated artifacts must preserve the prepared catalogue's semantic hash, and the compiler must execute after being copied alone to a temporary directory without installed application dependencies.

## Native evidence

The Android emulator runs the existing compatible development client, version 1.0.238 (192), with Phase 4 JavaScript. [Eight PNG/XML pairs and hashes](evidence/android-redesign-phase4/manifest.json) on source `02d2dc9` show Rates, Account, Settings privacy facts, the selected Unloan product, Calculate, Projection and Native Back. The full catalogue opens without setup questions. An optional update banner identifies its version and install action. Optional crash reporting remains undecided until an explicit choice; factual rows identify sent and excluded content, destination and access.

Calculate carries the selected Unloan row and its advertised 5.89% rate into both modes. Native Back returns through the product to Rates. This is development-client navigation and layout evidence. It does not establish final public-APK acceptance, physical-device behaviour, haptics, human-user validation or app performance. Phase 5 supplies paired friction journeys and the Android matrix.
